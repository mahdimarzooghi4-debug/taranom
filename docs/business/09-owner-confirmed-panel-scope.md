# TRN-BUS-009 — دامنه پنل‌های مورد تأکید مالک محصول

- وضعیت: ثبت تصمیم‌های صریح مالک محصول برای ادامه توسعه؛ جزئیات RBAC و اتصال‌های واقعی نیازمند قراردادهای فنی هستند.
- این سند تعداد نهایی نقش‌ها یا مجوزهای سامانه را تعیین نمی‌کند.

## سطح‌های محصول

- **عضو/بیمار:** عضویت، خدمات سلامت، نوبت‌دهی، پرونده سلامت و نسخه‌های خودش.
- **مدیریت ترنم:** چند سطح دسترسی؛ پنل باید صندوق داخلی ترنم و جریان‌های مالی مربوط را در حدود مجوز هر نقش نشان دهد.
- **مرکز درمانی:** مدیریت مرکز و بخش‌های آن، پزشکان وابسته و جریان‌های خدمات/درآمد مرکز در حدود قرارداد و مجوز معتبر.
- **نهاد حمایتگر/کارفرما:** مشاهده امور مالی مددجویان تحت حمایت در حدود دسترسی مجاز؛ کمک پرداخت‌شده از صندوق نیکوکاری داخلی ترنم نیز باید در گردش مالی مرتبط قابل ردیابی باشد، بدون افشای غیرمجاز اطلاعات درمانی عضو.
- **بیمه‌گر:** پنل مستقل بیمه در دامنه فعلی نیست؛ ترنم از API رسمی و مجاز بیمه‌گر استفاده می‌کند و اختیار پوشش نزد مرجع بیمه باقی می‌ماند.

## اصول محصول

- نوبت‌دهی یکی از خدمات اصلی ترنم است.
- نسخه صادرشده باید در پرونده ترنم عضو نیز باقی بماند و برای عضو قابل مشاهده باشد.
- دستیار هوشمند در غربالگری و راهنمایی ارجاع کمک می‌کند؛ انتخاب نهایی پزشک با بیمار است.
- مرکز درمانی می‌تواند چندبخشی باشد؛ بیمارستان نیز در همان پنل مرکز مدیریت می‌شود.
- همکاری مالی یا پرداخت حق عضویت برای حامی، مجوز دیدن پرونده درمانی عضو نیست.

## مرز اجرا

این تصمیم‌ها برای هدایت Backlog و کد رابط کاربر ثبت می‌شوند. اتصال واقعی هویت، نوبت، پرونده/نسخه، بانک/صندوق، مراکز، پزشکان و API بیمه‌گر فقط پس از قرارداد، مجوز، منبع داده و آزمون مستقل فعال می‌شود. این سند به‌تنهایی نقش RBAC، اختیار مالی یا بالینی، داده واقعی، API، قرارداد یا Release را ایجاد نمی‌کند.
