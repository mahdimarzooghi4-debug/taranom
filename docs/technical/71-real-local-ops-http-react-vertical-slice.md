## Design

Unlike the existing synthetic .NET domain kernels, offline measurement tooling, and disconnected member/center shells, this delivers a **genuinely running HTTP Backend ↔ Frontend** technical vertical slice that handles only the repository's already-public launch-blocker metadata. No private member/clinician/payment data is sent, queried or persisted. It is a local developer/operations diagnostic, not an IdP, clinical API, insurer, lawful service integration, Production backend or official readiness assessment.

- **Backend:** separate .NET 10 ASP.NET Web SDK app under \`src/Taranom.OperationsStatus\`; Kestrel **only localhost:4318**. Operator must provide explicit \`TARANOM_OPS_REPO_ROOT\` pointing to the public checked-out Git tree. Reads \`docs/governance/national-launch-blockers.json\` (not any real-world external evidence). No POST, auth token, CORS grant, clinical ID, API credential, user state, database or external network dependency.
- **Contract:** \`GET /internal/ops/v1/status\` requires exactly the 13 official Epic IDs + three named markets + national coverage; all 17 unique and BLOCKED_UNVERIFIED; release status DENIED_BY_DEFAULT; \`external_evidence_verified=false\` and \`real_release_approval_observed=false\`; bounded nonempty external evidence category names. Valid *denied manifest* produces 200 with \`runtime=LOOPBACK_PROCESS_ALIVE\`, \`inventory=SOURCE_BLOCKED_UNVERIFIED\`, \`releaseAllowed=false\`, \`verifiedIntegrations=false\` and public 17-item dimensions. Invalid/missing source or absent root => HTTP 503, zero dimensions and false approval fields. HTTP 200 proves **only** a localhost process and known blocked manifest, not real infrastructure, live service, legal/clinical rights or successful authenticated connectivity. POST 405; cache no-store, nosniff, frame-deny, restrictive CSP.
- **Frontend:** a separate React 19/TypeScript/Vite app in \`apps/ops-web\`, compiled and served same-origin by Kestrel after copying dist into local host wwwroot. Actual browser \`fetch('/internal/ops/v1/status')\` with \`credentials:'omit'\`, \`cache:'no-store'\`. Strict 17-ID source validation, LOADING/UNAVAILABLE/LOOPBACK_ONLY states, refresh, filters 13 Epic/3 markets/national scope; Persian RTL, no hallucinated 0 records, clinical or financial values, credentials or external request. Existing clinical center and member shells stay disconnected.
- **QA:** thirteenth CI job builds both real C# and TS/Vite, starts the real localhost process, executes Python HTTP status/header/POST checks, and runs five Chromium Playwright end-to-end tests on the actual same-origin .NET/React pair. Keep all inherited 12 independent Postgres test, .NET, member and center built Chromium, public Git history, workflow trust, external-AI ban and national DENY jobs.
