# TRN-TECH-143 — Sprint 134: self-hosted synthetic Shadow Learner and independent evaluation

**Real executable offline algorithm.** With explicit fixed `test:` sources, Python trains an intercept + single-feature ordinary least-squares reference learner using genuine Decimal calculations. This learner is a narrowly scoped **technical regression algorithm**, NOT an approved medical model or recommended Production family. `TRAINING` sources are fully pinned to an immutable manifest and **never** overlap with independent held-out `INDEPENDENT_EVALUATION` sources/subjects. Baseline is the mean observed TRAINING value; held-out MSE and MAE for baseline and Shadow are measured without winner selection, quality thresholds or automatic promotion.

**Durable technical structures**: two append-only SQLite tables `shadow_training_runs` and `shadow_benchmarks`, FK to registered frozen datasets/model versions and DB UPDATE/DELETE denial triggers. The deterministic OLS artifact (algorithm, intercept, slope, baseline mean, manifest SHA, source list, training input SHA and model/version) is stored as canonical JSON with SHA256 digest; the registered model version pins the same artifact SHA in the same BEGIN IMMEDIATE transaction. Training replay and benchmark replay are idempotent/isolated per tenant with deterministic digest comparison and exact request scope. Benchmarks independently reattest both artifact and source manifest digests before evaluation. Missing source, tampering, zero feature variance, NaN, source overlap, wrong tenant or stale lineage all deny.

**Runnable interfaces**: the existing opt-in `OfflineRegistry`, CLI (`train-shadow`/`benchmark-shadow`) and localhost synthetic HTTP (`POST /internal/ai-test/v1/shadow-training`, `/shadow-benchmarks`), plus read inventory projections. All are disabled outside `CI_EPHEMERAL_ONLY`; HTTP does not authenticate real staff. No external APIs, clinical data or real training entitlement. This Sprint never selects a model, approves a threshold, calls an inferencer or promotes any candidate. Declared results have `candidate_approved=false`, `winner_selected=false`, `human_approved=false`, `production_allowed=false`.

**Non-goals / next dependencies**: real lawful data collection, independent medical and technical committee approval, authenticated admin control plane, real artifact/runtime adapter selection, self-hosted operational infrastructure and Stage are separate decisions. `DENIED_BY_DEFAULT` for production and nationwide release; stacked PR remains Draft/Open/Unmerged. Acceptance: full GitHub CI with real SQLite, HTTP and browser tests and inherited PostgreSQL/Chromium regressions; do not claim release authorization from CI alone.
