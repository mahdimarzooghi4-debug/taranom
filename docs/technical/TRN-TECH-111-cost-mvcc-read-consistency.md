## Verified actual defect

`PgSyntheticCostAwarenessJournal.ReadAsync(Guid)` currently opens a default PostgreSQL READ COMMITTED transaction and calls `ReadLockedAsync`, whose **header SELECT ... FOR UPDATE** takes the same write lock as `RecordAsync` / `RegisterAsync`. All browser and HTTP readers, including as-of event timeline readers, could therefore be blocked by a mutation/long uncommitted transaction. Deleting just FOR UPDATE under READ COMMITTED would also risk torn reads of preview header vs appended choice events and paired audits.
