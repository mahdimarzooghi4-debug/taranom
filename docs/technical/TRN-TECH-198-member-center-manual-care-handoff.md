## Member hand-carried ticket

All fields originate from the canonical immutable source and never user guesses. The last event UUID binds the exact observed tip as well as the root UUID. Case/member input change, uncertain write, claim edit, fresh source read while in flight, or historical version selection hides the ticket. It contains only opaque `test:` references, no personal data, credentials, signatures or medical document payload. A ticket is NOT consent, authorization, verified service, messaging, referral, or a bearer access token. It has no transport or storage; a human copies it manually.

Do not choose/switch an actionable case based only on the JSON.
