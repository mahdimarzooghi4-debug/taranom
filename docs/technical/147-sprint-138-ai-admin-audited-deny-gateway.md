## Implemented
- `POST /internal/demo/v1/ai-admin/denials` accepts only an exact, bounded JSON body of `requestRef`, `operation`, `targetRef`; all identifiers are `test:` and operation must be exactly one of the eight domain operations from Sprint 137. Unknown actions, real identities, impersonation headers and unexpected fields fail closed.
- Domain `AiAdminIdentityBoundary.Decide` is always invoked with **no configured real trust authority**, so even an incoming JWT cannot grant real authenticated operator/committee identity, register or activate an AI model, operate a training worker, or select a clinical candidate.
- A **real ephemeral PostgreSQL** `internal_test_ai_admin_denial` append-only table records denied requests only, with database UPDATE/DELETE denial trigger, contiguous sequence, content-hashed `event_sha` chained to previous SHA, unique requestRef/idempotent exact replay and changed replay conflict. A global transaction advisory lock serializes concurrent inserts and the full history is verified before append or read. The journal NEVER stores raw Authorization tokens, personal data, passwords, real tenant/member identities, actual AI model state, or medical decision fields.
- `GET /internal/demo/v1/ai-admin/denials/{requestRef}` checks and returns the persisted denial receipt with `adminAuthenticated=false`, `operatorAuthorized=false`, `committeeApproved=false`, `productionAllowed=false` and `trainingAllowed=false`. A read receipt has **zero approval powers**. Database errors or evidence mismatch return 503; no fake success.
- Full exact-head CI runs the real Kestrel → Npgsql → PostgreSQL adversarial HTTP suite, including all eight operations, replay/conflict, missing/invalid routes, forged admin/cookie/origin headers, bogus Bearer and no raw-token disclosure, concurrent request writes, forced UPDATE rejection, stable hash chain and persistent read. The existing ephemeral PostgreSQL backup/recovery will automatically attest the new table and database immutability trigger alongside existing tables. All other tests run unchanged, no filter or skipped gate.
