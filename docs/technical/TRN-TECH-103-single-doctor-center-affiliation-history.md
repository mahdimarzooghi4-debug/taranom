## Functional requirement

A center may record an unverified physician, assign it to one or several departments in the SAME center, and end its affiliation. It must be possible to audit this *one doctor's* sequence, even when unrelated department and other-doctor events are interspersed. Ended affiliation must disappear from CURRENT department assignment but remain in prior version history. Do not create approval, reactivation, true qualification, patient access, corporate network manager or financial payment.

Require exact expected current center version (409 stale), replay the canonical pure reducer to a selected historical prefix M (503 if divergence), 404 if this doctor did not belong to that center at M. Show only its status PendingIndependentVerification or Ended, current department refs at M, and a bounded page of its RecordDoctorAffiliation, AssignDoctorToDepartment and EndDoctorAffiliation accepted event kinds at or before M, ordered by ORIGINAL global journal version (may be sparse). `afterVersion` is an exclusive global event-version cursor, not an assumed contiguous doctor counter; `nextAfterVersion` is the last returned matching original event version.
