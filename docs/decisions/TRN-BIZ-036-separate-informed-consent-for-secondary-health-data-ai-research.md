# TRN-BIZ-036 — استفاده ثانویه از داده سلامت فقط با رضایت مستقل عضو، حفاظت و مجوز قانونی

- **وضعیت: ACCEPTED — سیاست Business؛ پردازش داده واقعی/آموزش مدل NOT APPROVED**
- تاریخ: 2026-10-09
- منبع تصمیم: تأیید صریح صاحب ایده در گفتگو
- عبارت مصوب: «استفاده ثانویه از داده‌های سلامت برای پژوهش و آموزش و بهبود AI فقط با رضایت آگاهانه و مستقل عضو، حفاظت داده و مجوزهای لازم مجاز باشد.»
- مرتبط: TRN-BIZ-035 (کنترل عضو و دسترسی محدود تیم درمان)، TRN-BIZ-033 (اختیار غیرتشخیصی AI)، TRN-BIZ-034 (فوریت و حریم خصوصی)، TRN-BIZ-029 (پرداخت‌کننده اشتراک مالک داده نمی‌شود).
- رجیستر: TRN-DEC-042 (سیاست اصلی استفاده ثانویه ACCEPTED؛ الزامات قرارداد داده و صحت رضایت OPEN)، TRN-DEC-005 (حفاظت و حقوق داده).

## سیاست مصوب

1. **هرگونه استفاده ثانویه از داده‌های سلامت اعضا برای پژوهش، آموزش یا بهبود هوش مصنوعی ترنم صرفاً مشروط به سه شرط هم‌زمان است:** (الف) **رضایت آگاهانه و مستقل عضو** برای این هدف ثانویه، (ب) **حفاظت مؤثر و معتبر از داده سلامت** و (ج) **مجوزها و مبانی قانونی لازم**. هیچ‌کدام از این سه شرط جایگزین دیگری نیست.
2. **رضایت برای خدمات درمانی، تشکیل پرونده سلامت، عضویت، پرداخت حق اشتراک یا اشتراک محدود اطلاعات با تیم درمان، رضایت پژوهشی/آموزشی محسوب نمی‌شود.** همچنین پرداخت‌کننده سازمانی یا نهاد حمایتی نمی‌تواند صرف پرداخت عضویت این رضایت را از جانب فرد فرض کند.
3. این مصوبه **اصل امکان استفاده ثانویه مشروط را می‌پذیرد، نه انتقال خودکار سوابق بیماران به Dataset آموزشی**. تا زمان احراز معتبرِ هر سه شرط برای دامنه همان استفاده و تصویب قراردادهای داده، منبع قابل استفاده برای پژوهش/AI محسوب نمی‌شود.
4. داده‌های دارای هویت، مستعارسازی‌شده یا غیرقابل‌شناسایی نیز نباید **بدون بررسی انطباق حقوقی و شروط مصوب** به بهانه تغییر شکل داده، استثنای خودساخته از سیاست رضایت مستقل بگیرند. نوع داده و شکل حفاظت بعداً تعیین می‌شود.
5. استفاده از داده برای **فروش داده سلامت، ارائه آن به کارفرما/حامی، استفاده تجاری مستقل یا دادن دسترسی به پیمانکار AI** از این تصمیم استنباط نمی‌شود. هیچ مجوز اشتراک با شخص ثالث صادر نشده است.
6. **آموزش یا بهبود مدل** به‌خودی‌خود **فعال‌سازی مدل در تصمیم بالینی، ارتقای Production یا جایگزینی پزشک** نیست. تصمیم‌های قبلی درباره غربالگری غیرتشخیصی و تشخیص/درمان توسط متخصص مجاز پابرجا هستند.

## موارد باز و پیش‌نیاز اجرا

- **TRN-DEC-042 / PARTIAL:** اصل اجازه مشروط پذیرفته شده؛ هدف/دامنه دقیق رضایت، روش اثبات و مدیریت آن، امکان و اثر پس‌گرفتن رضایت، نگهداری و حذف داده، استفاده از مشتقات/نسخه‌های Dataset، حقوق نمایندگان قانونی و نحوه اعتبارسنجی مستقل باید در قرارداد داده/حقوقی تعیین شوند؛ **هیچ رفتار پیش‌فرض حدس زده نمی‌شود**.
- **TRN-DEC-005 / OPEN در جزئیات:** طبقه‌بندی، کمینه‌سازی، امنیت، محدوده پردازش/اقامت داده، اشتراک بیرونی، نظارت، رخداد و تکالیف قانونی باید قبل از پردازش واقعی تعیین و آزموده شوند.
- **TRN-DEC-010 / OPEN در سازوکار AI:** انتخاب خانواده مدل، مالکیت/اجرای داخلی یا طرف ثالث، جمع‌آوری داده آموزشی، ارزیابی مستقل، گیت انسان و سیاست نسخه‌گذاری مدل‌ها تصمیم جداگانه می‌خواهد. این مصوبه هیچ مدل/موتور/انتقال خارجی را تأیید نمی‌کند.
- هیچ رضایت واقعی یا مجوز قانونی، داده فردی، دیتاست، آموزش مدل، پردازش واقعی، API، کد، Stage، QA، Release یا Production در این سند ایجاد/احراز نشده است.

## سؤال کلان بعدی

**راهبرد مالکیت و کنترل هوش مصنوعی ترنم چگونه باشد؟** توسعه و اجرای کاملاً داخلی و تحت کنترل ترنم، استفاده از ارائه‌دهندگان بیرونی با قرارداد و کنترل‌های قانونی، یا مدل ترکیبی؟ این سؤال صرفاً تصمیم راهبردی کسب‌وکار و حاکمیت است، نه انتخاب زیرساخت یا مدل فنی.
